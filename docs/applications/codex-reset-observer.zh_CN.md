# Codex 重置观察器 v2.2

面向 240 × 320 AI Passport 的独立只读公告工具，数据来自
[Codex Resets](https://codex-resets.com)。它不是 OpenAI 官方软件，也不是个人额度表。
界面参考原站的奶油纸底、墨色描边、黄色时间贴和粉蓝统计卡。

## 四页与按键

上下键切换“概览、统计、公告详情、设置”。前三页确认键请求刷新。
设置页按确认进入选项，上下选择、确认修改或进入；末项“返回概览”用于返回。
按下底部确认键立即出现“准备休息”圆形进度弹窗，中心为轻量几何月亮，
不显示百分比或秒数。500 ms 内松开，执行原短按用途；
按住达到 500 ms 但未满 2 秒松开，仅取消，不执行原动作。满 2 秒圆环完成并提示
“松手，晚安”，不需要二次确认。所有键连续松开 250 ms 后，仍须通过既有 HTTP、
无线和外设安全关闭流程才实际入睡，不能在共线 GPIO 仍被拉低时入睡。
进度按单调时间戳计算，持久 LVGL arc 约每秒更新 25 次，不逐帧重建页面。
其他按键、焦点变化或输入队列溢出会取消；蓝牙配网时阻止休眠，HTTP 忙时必须
先按原有超时边界结束请求。子页短按保存/返回，清除网络页短按确认清除、上下取消。
独立电源键保留硬件开关用途，不当导航或休眠键，因为 BSP 尚无已确认的短按事件。

概览显示距公告/观察事件的时间，以及明确时区的绝对日期和时分。常规重置和储备
额度分开标明，计划过时仍等待执行确认，AI 预测不是承诺。统计显示 API 的累计
次数、平均间隔、距上次天数；缺失值显示未知。公开接口没有网站“最长间隔”字段，
设备不会猜测或硬编码。详情区分站点生成时间（UTC）与最近成功检查时间。

## 设置与省电

- Wi-Fi 开关会保存。关闭保留凭据，但停止扫描、蓝牙配网、重试与自动重连；
  开启后连接已保存网络。
- 自动同步可选 5/15/30/60 分钟，默认 15 分钟。手动和唤醒刷新可绕过自动周期，
  但有 30 秒防抖，且必须遵守失败退避及服务端 Retry-After，界面显示剩余等待。
  五分钟不是官方公布的硬性限频。
- 本地时间使用明确的固定 UTC 偏移，每步 15 分钟，范围 UTC−12 至 UTC+14。
  默认 UTC，不猜测位置，不自动切换夏令时。
- 亮度 20/45/75%。普通查看状态 30 秒调暗，2 分钟关背光；此时首次输入只唤醒。
  设置或配网期间保持显示。
- 配网和清除网络是不同操作；清除页短按确认才执行，上下取消。
- 深度休眠仅通过手动按满圆环并松开进入，不再弹二次确认。睡眠时不联网、不定时唤醒、不后台更新。
  以底部确认键为主要唤醒入口，**仍需实机验证**；入睡前松开所有键。若无法唤醒，使用硬件
  电源控制恢复。三个功能键共用 GPIO0，上下键也可能唤醒；软件不能区分哪一个电阻梯按键造成 LOW 唤醒。

入睡前必须等 HTTP 完成清理和无线关闭确认。按键在稳定松开后从 ADC 转为数字
GPIO，再按板级顺序关闭电量计、codec、总线和屏幕；不可逆关闭之后的失败会安全
重启。取消休眠恢复服务并等待按键松开。带校验的 RTC 缓存可跨深睡保存，断电不保证。
唤醒先显示旧数据；只有 Wi-Fi 开启才连接，完成本次 SNTP 校时后更新，并保留退避。
没有自动再次入睡，不声称未经测量的续航或休眠电流。

## 配网与安全边界

开启 Wi-Fi 后，进入配网页按上键，手机微信打开完整名称为
**蓝牙配网-FoloToy AI PASSPORT** 的小程序，选择 `BLUFI_FoloPassport`，
提供 2.4 GHz 网络信息。窗口仅显式按键开启，180 秒、成功或取消后关闭。
密码不嵌入固件、不写日志；获得 IP 后才保存到普通 NVS，失败候选不会覆盖原网络。

传统 BLUFI 不认证对端，完成 DH 协商后也不强制每个接收帧加密。附近参与者在配网
窗口内可能替换为可连接的新网络，因此仅在可信近场环境操作。本应用保留官方参考
提交 `9c039cc5127f22072afa83bedb7fa3d8efe635ad` 的协议，没有私有入口挂钩或自制加密。

HTTPS 使用 CA 证书包与主机名校验，不跟随重定向，有响应/JSON/超时边界、ETag
缓存及退避。网络需要 DNS/NTP/HTTPS，不支持网页认证热点。更新失败保留缓存。
界面不展示服务端自由文本、SSID 或密码。

## 构建与验证

激活 ESP-IDF 5.5.3 后，在项目目录显式运行：

```bash
python3 tools/apply_blufi_safety_patch.py --apply
./tools/validate.sh
```

脚本验证 SDK 版本和精确源码哈希，拒绝未知修改，重复应用安全。补丁和清单位于
`tools/patches/`，仅修正短分片及 1025 字节重组边界，满足本应用最大 DH 消息，
不改变加密语义，不作为通用上游修复。共享 SDK 的其他工程也受此本地补丁影响，
若需原始基线请另用干净 SDK。固件门禁验证补丁并使用全新配置，按外部上拉的按键
电阻梯要求关闭内部睡眠 GPIO 电阻。

主机测试覆盖解析、HTTP/RTC/退避、导航/设置/时间转换、Wi-Fi OFF/延迟事件、
按键 ADC 交接、休眠顺序和 SDK 分片边界。
[真实 LVGL 预览](../../tools/reset_ui_preview/README.zh_CN.md)使用相同的 12/16 px
中文字形与 BSP 半径 30 的圆角裁切，并检查反复换页内存；不等于实机照片或验收。

待实机验证：屏幕/字形、按键与确认键唤醒/无立即唤醒、小程序兼容性、Wi-Fi/TLS、
NVS 保存、取消恢复、运行内存及整板电流。合并镜像从 0x0 刷写，可能重置设置，
需另行批准。v1、v2 和 v2.1 已留档，本次构建不会自动更新或刷写设备。

## 确认键唤醒的电气依据

板级定义为 10 kΩ 外部上拉、确认键 2.2 kΩ 下拉，3.3 V 时约 595 mV。
ESP32-C3 输入 LOW 最大保证电压是 0.25 × VDD，即 3.3 V 时 825 mV，
名义数值支持确认键拉低唤醒；上下键名义电压也在 LOW 范围内。
这不是实机唤醒测试，正常 ADC 识别窗口也比数字 LOW 保证范围更宽。
见[官方 ESP32-C3 数据手册直流特性](https://documentation.espressif.com/ESP32-C3_Datasheet_en.pdf)。
保留原有稳定松键、释放 ADC、数字 GPIO 高电平检查后再配置 LOW 唤醒的流程。
醒后输入须连续松开 250 ms 才放行，长于 180 ms 单击延迟，唤醒按键不会触发刷新
或立即再次进入休眠提示。
