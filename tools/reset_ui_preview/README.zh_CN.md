# 真实 LVGL 重置应用预览

主机工具直接编译固件 `main/reset_ui.c`、`reset_presenter.c`、`reset_text.c`、
有界数据解析器及生产 `reset_hold.c`。使用固定的 LVGL 9.5、240 × 320 RGB565、
40 行局部缓冲区和保持不变的 24 KiB LVGL 内存池。刷新回调调用真实 BSP 圆角行
裁剪函数，半径取自 `bsp_display.h` 的 30 像素。这不是 HTML 仿制、设备实拍、
网络请求或刷机操作。

## 运行

需要 C/C++ 编译器、CMake、带 Pillow 的 Python，以及已解析的托管 LVGL 源码。
在仓库根目录执行：

```bash
python3 tools/render_reset_preview.py
python3 tools/render_reset_preview.py --feed /path/to/captured-status.json
```

可选数据文件必须已在本地。真实固件解析器会验证它，以 `generated_at` 为参照
时钟、电量不可用。捕获数据屏幕命名为 `00-captured-*`，包括首页、全部正文页和
概览；不能当作当前实时查询。其他屏幕均为明确标注的模拟输入。可指定
`--build-dir` 和全新 `--output` 目录；已有输出不会被删除。工具不修改托管 LVGL。

## 公告和正文约定

四个顶层页面依次为公告、最近已执行重置概览、统计、设置。首页短按确认进入
正文子页面；正文上下翻页、短按确认返回首页。长按休眠保持独立。设置有七行，
其中自动休眠默认 5 分钟，可选关闭（0）、5、10、30 分钟。

- 首页只在 `latest_reset` 和 `scheduled_reset` 之间比较 `announced_at`，
  不把预测的 `observed_at` 当作公告。首页只显示时间：中文相对时间为主视觉，
  绝对本地日期为辅，类型/状态低调呈现；不显示正文摘要或密集阅读说明。
- 预计时间优先使用明确计划，标注“计划”，按固定 UTC 偏移显示。空时间保持待定；
  超时计划仍等待确认。没有计划时，仅将未过期预测的原始 `forecast_window`
  标为预测；过期预测不作为有效计划，也不从平均间隔推算时间。
- 概览使用最近已执行记录，区分 CODEX 常规额度重置和备用额度发放。中文相对
  时间为主、本地精确日期为辅，并注明“时间依站点记录”。不把公告/观察时间
  宣称为精确执行时刻。
- 原文最多保留 256 个 UTF-8 字节。按照实际所选 LVGL 字形宽度（含字偶距）排入
  178 像素；优先空白换行，无空格长词/URL 按完整码点拆分。CR/LF、TAB 规范化。
- 首页短按确认仍进入正文。16px 固定正文每页七行、最多八页。仅保留低调日期、
  小页码和域名，不显示常驻操作说明；只有发生异常时才显示提示。
  字节或页数超限有明确提示。未覆盖字符替换为 `?` 并提示。原文不翻译、不执行，
  不作为富文本解释。
- 标签内容由有界静态缓冲区持有，不增加正文堆分配、完整 CJK 字库、远程翻译，
  也不承诺可点击链接或二维码。可读汇总站点域名为 `codex-resets.com`。

12/16px 字库覆盖固定 UI 和可打印 ASCII；24px 仅有 25 个字形，直接从中文相对
时间格式函数提取。复现及许可见[资源记录](../../assets/README.zh_CN.md#codex-重置观察应用字体子集)。

## 检查能证明什么

工具检查两种正文字体清单、较大字号子集、已知缺失 U+9F98、每个可见标签实际
绑定的字体、行宽、正文预留行高以及屏幕/父对象边界。模拟输入覆盖：

- 首页、所有顶层/子页面、七行设置、离线/旧缓存及联网错误
- 较新的计划公告、常规/备用已执行或计划状态、超时/空时间计划、原始预测、
  仅预测无公告、过期/截断预测
- 256 字节宽字符文本的全部四页、连续 URL 的全部两页、emoji/缺失中文替换、
  CR/LF/TAB，以及源文本字节截断
- 换行密集文本的全部八页、明确页数上限提示、越界页码收敛
- 从刚刚到 99 天 23 小时及超过 9999 天的中文相对时间

正文页在相同预热后执行 500 次页码/截断状态变化，要求活动分配数和空闲字节
完全一致。四个顶层页面也先运行相同预热，再测量 1000 次切换。每 500 次的
终点在本次诊断版本中均为空闲 4664 字节、208 个活动块；分别对比每个相应预热阶段，
活动块数及空闲字节必须完全一致，无增长容差。
最终 v2.3 检查 90248 个可见标签，缺字和裁剪均为零；保持不变的 24 KiB 内存池
峰值占用 17712 字节，最终顶层页空闲 4664 字节。这是主机池结果，不是设备堆。

默认输出到 `build/reset-ui-preview/screens/`，包括 PNG/PPM、模拟状态拼图、
`audit.txt`、源码哈希及 `manifest.json`。即使生成了图片，检查失败仍返回非零。
改动后应检查真实图片。设备亮度、电量 ADC、物理按键、蓝牙、Wi-Fi/HTTPS 压力、
凭证及真机中文字形均不由此工具验证；主机渲染不能等同 `Device tests: PASS`。

## 仅在配网页面显示的 Wi-Fi 诊断

配网页面区分正在启动、初始化失败、未保存网络、正在连接第 `n/5` 次、等待重试，
以及已联网但凭证保存失败；设置页显示相应简短 Wi-Fi 状态。诊断只显示数字码：
`E` 是错误码，`D` 是最近一次断开原因。不显示 SSID 或密码，也不宣称已确认根因。
运行错误和凭证持久化错误相互独立，可以同时显示。取得 IP 后若保存失败，原有
配网倒计时仍保持可见。只显示时间的首页及七行正文没有改动。
`37`–`45` 场景涵盖 INT32_MIN/MAX、UINT16_MAX、两类错误同时发生、配网倒计时
叠加保存失败，以及全部启动/重试状态。

`hold-to-sleep-progress-strip.png` 展示 0/25/50/100 填充状态，界面本身无数字。

暖奶油/墨色弹窗、几何月牙和稳定 LVGL 圆环均未改变。不使用截图缓存或倒数。
弹窗期间保留下方页面并隐藏绘制，关闭后恢复。500 帧进度压力检查对象身份/数量
稳定、零删除、预热后分配完全相同、内存分配器正常。另有 100 次取消/打开关闭
循环检查短按隐藏期和下方对象不变。最终进度期间 21 个对象、216 次活动分配，
前后均空闲 4744 字节；取消关闭后 186 次活动分配、前后空闲 6496 字节。
